\section{研究背景及意义}
实时渲染（Real-time Rendering）是计算机图形学中用于在极短时间内生成高质量动态图像的核心技术。随着硬件光线追踪加速核心的普及，针对混合渲染架构设计专门的引擎工具，其意义体现在以下几个方面：

\textbf{混合管线调度与同步至关重要}。混合渲染涉及光栅化与光线追踪的大量切换，其性能高度依赖于资源同步的准确性。设计高效的调度工具应能帮助开发者自动执行复杂的管线屏障推导任务，以优化显存访问，确保渲染指令能够更好地反映硬件并行特征。

\textbf{信号降噪与画质重建同样重要}。光线追踪在 1 SPP 极端采样下会产生巨大方差噪声。因此，工具的设计需要提供高效的时空滤波算法实现，以便用户（开发者）能够直观地理解降噪过程中的权重分布与方差演变，并根据场景需要对重建参数进行灵活调整。

\textbf{应用开发与集成也是不可忽视的一环}：通过设计模块化的渲染引擎架构，可以降低光线追踪技术的应用门槛，使更多的图形开发者能够轻松地将混合渲染特性集成到他们的三维应用中。这对于面临大规模场景表现力不足的开发者来说尤为重要。

\textbf{性能评估与优化也是设计工具时应考虑的关键因素}。工具应具备实时的耗时监测与画质对比功能，以便用户能够评估不同 Pass 的开销、识别性能瓶颈并进行针对性调整。这有助于提升系统在实际硬件上的运行效率。

\section{国内外研究现状与发展}
混合渲染技术在影视、游戏及虚拟现实领域得到了广泛应用，并且在图形学研究中仍然是一个活跃的主题。
\begin{itemize}
    \item \textbf{图形 API 演进}：从传统的 OpenGL 状态机演进至 Vulkan/DX12 的显式控制模式。Vulkan 1.3 引入的动态渲染特性进一步简化了管线管理。
    \item \textbf{硬件加速技术}：NVIDIA RTX 与 AMD RDNA 架构通过专用求交单元（RT Core）大幅提升了射线追踪速度，使得实时路径追踪成为可能。
    \item \textbf{渲染调度架构}：EA Frostbite 引擎提出的 FrameGraph 概念引领了行业趋势，现代引擎如虚幻引擎（RDG）正致力于实现更智能的资源复用与多线程录制。
    \item \textbf{信号重建算法}：SVGF（时空方差引导滤波）及其后续变种（如 ASVGF）仍然是当前 1 SPP 降噪领域的主流方案，同时深度学习降噪（如 DLSS）也在快速发展。
\end{itemize}

\section{相关技术}

\subsection{基于物理的渲染方程 (PBR)}
给定表面点 $p$ 与出射方向 $\omega_o$，计算出射辐射度 $L_o$ 的核心方程为：
\begin{equation}
    L_o(p, \omega_o) = L_e(p, \omega_o) + \int_{\Omega} f_r(p, \omega_i, \omega_o) L_i(p, \omega_i) (n \cdot \omega_i) d\omega_i
\end{equation}
其中 $f_r$ 为双向反射分布函数（BRDF），$L_i$ 为入射光。本系统利用该物理模型确保材质表现的真实性。

\subsection{混合渲染管线与 G-Buffer}
混合渲染器结合了光栅化的高效几何提取能力与光线追踪的物理光影特性。
\begin{enumerate}
    \item \textbf{几何采集}：利用光栅化生成多附件 G-Buffer（Albedo, Normal, Depth, Motion）。
    \item \textbf{光影预测}：基于 G-Buffer 信息发射探测射线，计算阴影与反射。
    \item \textbf{数据合成}：将光栅化材质与光追生成的辐照度信号进行物理加权合并。
\end{enumerate}

\subsection{SVGF 时空一致性降噪技术}
针对 1 SPP 的蒙特卡洛噪声，系统采用 SVGF 算法。其核心在于利用时域累积（EMA）增加有效样本数：
\begin{equation}
    E[L]_t = \alpha L_t + (1 - \alpha) E[L]_{t-1}
\end{equation}
并结合 A-Trous 滤波器执行保边过滤。该算法能捕捉时序关系并利用亮度方差引导空间模糊，实现信号的高质量重建。

\subsection{Vulkan 显式资源管理与同步}
Vulkan 提供了极高的硬件控制权：
\begin{itemize}
    \item \textbf{内存控制}：利用 VMA (Vulkan Memory Allocator) 进行池化管理。
    \item \textbf{同步原语}：通过 Pipeline Barrier 实现 Image Layout 的显式转换。
    \item \textbf{并行调度}：支持在多个 CPU 线程上录制 Command Buffer。
\end{itemize}

\subsection{Dear ImGui 可视化框架}
JavaFX 之于传统应用，Dear ImGui 之于高性能渲染器。它采用 Immediate Mode UI 思想，具备极高的实时性，支持在不影响渲染帧率的前提下，为用户提供丰富的调试控件、折线图及中间纹理的可视化输出。

\section{本文的主要工作}
本文设计并实现了一个基于 Vulkan 的实时混合渲染引擎，本系统共包括三个大模块：
\begin{enumerate}
    \item \textbf{资产与基础设施模块}：负责 GLTF 2.0 模型解析、异步 TaskSystem 调度及 VMA 显存管理。
    \item \textbf{渲染调度引擎 (RenderGraph)}：实现基于 DAG 的 Pass 编排、资源生命周期分析及自动化屏障推导。
    \item \textbf{混合计算与重建模块}：包含延迟光栅化管线、Ray Query 光追计算、SVGF 降噪及 TAA 后处理输出。
\end{enumerate}
