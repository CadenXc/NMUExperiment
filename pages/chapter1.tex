\chapter{绪论}

\section{研究背景及意义}
渲染是指通过软件算法将包含几何、视点、纹理和照明等信息的三维（或二维）模型转换为最终二维图像的技术。
实时渲染是聚焦于制作和分析实时图像的计算机图形学的子领域。
观察者对屏幕中看到的图像做出反应和操作，这些反馈会对下一张生成的图像产生影响。这种包含反应和渲染的循环会以一个很高的速度发生，以至于观察者没有反应过来自己在看一系列图像，而是沉浸在一个动态的过程中。
通常会使用每秒显示的帧数（frames per second，FPS）或者赫兹（Hertz，Hz）来衡量图像显示的速率。一般大于 30FPS 的渲染被称为实时渲染，10FPS 左右的我们称为可交互渲染，再慢的就是离线渲染。
目前广泛应用在强交互的3D游戏和带3D的应用中，例如，游戏，VR/AR，虚拟仿真等，有广泛的应用前景和商业价值。

在实时渲染领域，主要有两种渲染技术：光栅化和光线追踪。光栅化技术历史悠久，是指把图像显示在屏幕上的过程。因为契合GPU 的 SIMD（Single Instruction Multiple Data）并行计算模型，光栅化能够以极高的效率处理大量的几何数据，适合于大规模场景的渲染，从而。然而，光栅化在处理复杂的光影交互（如软阴影、全局照明和反射）时存在局限性，难以实现物理上准确的视觉效果。
光追技术则通过 ray tracing（射线追踪）来计算反射、折射、可见性以及阴影，从而实现更精确的视觉效果。由于光线采样的随机性，难以契合GPU 的 SIMD 并行计算模型，并且需要多次迭代，耗时较长，主要用于离线渲染领域。

随着 GPU 硬件能力和图形算法的飞速进步，实时光线追踪技术已逐渐从实验室走向工程实践。
混合渲染是一种结合了多种渲染技术的方法，能结合旨在能结合光线追踪和光栅化各自的优势，也是目前主流的研究方向。

\section{研究现状}

图形渲染管线经历了长期的演进过程。20 世纪 90 年代末，开发者只能通过图形 API 提供的固定流程处理图像。随着统一着色器架构（Unified Shader Architecture）、GPU 驱动的几何剔除以及瓦片渲染（Tiled Rendering）等技术的出现，GPU 的自由度不断提升，图像编程变得愈发灵活。

2018 年是实时渲染的分水岭，Microsoft 发布了 DXR（DirectX Raytracing）框架，NVIDIA 推出了基于 Turing 架构的 RTX 平台，让实时光线追踪成为可能。。Vulkan 作为新一代跨平台图形 API，由 OpenGL 的开发团队 Khronos Group，打造的现代图像学 API， 也提供了官方的光追扩展，本次引擎采用该 API 完成渲染构建。

由ID SoftWare 开发的《德军总部3D（Wolfenstein 3D）》 《毁灭战士（DOOM）》取得了巨大成功，游戏引擎的概念也由约翰卡马克创建。 DOOM引擎是第一个用于商业授权的引擎，后来开发的Quake引擎是真正的 3D 引擎, 人们普遍认为游戏《雷神之锤》带来了独立3D显卡的革命。
如今的商业游戏引擎市场基本上是Unreal, Unity两巨头，在开源领域也有Orge，Godot等引擎，给许多引擎和渲染开发者提供了优秀的学习资料，促进了游戏引擎，渲染领域的发展。

除了渲染引擎整体的研究，也有对实时渲染相关问题的研究。实时渲染需求时效性，渲染质量论不如离线渲染，目前是在保证时效性下提高渲染质量。即使现在的硬件发展革新了实时渲染领域，在半透明等领域还，需要光线大量采样，目前GPU的算力仍无法满足需求。实时渲染的光线追踪使用 temporal，以低开销通过从历史图像获取数据，之后通过滤波去除高噪点信息，获取较高质量的结果。
SVGF，在时空间采样和滤波，能满足实时渲染下对性能的要求，也能获得较好的图像效果。

\section{本文研究内容}
本文基于 Vulkan 1.3 规范设计并实现了一个三维实时混合渲染引擎，主要研究内容包括以下几个方面。
\begin{enumerate}
    \item 研究 Vulkan 1.3 渲染管线，利用动态渲染、同步 2.0 等新特性优化引擎底层架构，简化资源管理流程。
    \item 设计并实现基于 \texttt{RenderGraph} 的资源调度模块，实现显存资源的自动生命周期管理与高效屏障同步。
    \item 构建混合渲染管线，结合光栅化的高效几何处理能力与光线追踪的物理精确照明，实现高质量的软阴影与反射效果。
    \item 研究并实现实时降噪与时空重构算法，针对低采样率的光线追踪信号进行处理，提升最终图像的视觉质量。
\end{enumerate}

\section{论文总体结构}
以下是对本论文各个章节的概要：
\begin{itemize}
    \item \textbf{第一章 引言}：介绍实时混合渲染的研究背景、国内外现状，并简述本文的主要工作。
    \item \textbf{第二章 理论基础}：深入分析 PBR 物理模型、Vulkan 渲染机制及硬件光追原理。
    \item \textbf{第三章 需求分析}：从可行性、业务流程、功能与非功能指标等方面详细阐述引擎需求。
    \item \textbf{第四章 概要设计}：论述系统分层架构、功能模块划分及显存逻辑表结构设计。
    \item \textbf{第五章 详细设计}：以需求为基础，对渲染图算法、光追逻辑及时空重建模型进行细致设计。
    \item \textbf{第六章 系统实现与测试}：展示核心代码实现，通过功能测试用例与性能数据验证系统有效性。
    \item \textbf{第七章 总结与展望}：总结全文工作并指出未来改进方向。
\end{itemize}
