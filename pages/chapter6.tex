\section{核心功能模块实现要点}

\subsection{基于 RAII 与延迟队列的资源管理实现}
系统通过 \texttt{ResourceManager} 实现了对 Vulkan 句柄的安全封装。
\begin{itemize}
    \item \textbf{延迟销毁 (Deletion Queue)}：针对异步移除模型导致的崩溃问题，系统通过 \texttt{std::function} 容器存储销毁回调。每帧结束时更新 \texttt{m\_CurrentFrame}，仅当资源超过 3 帧渲染循环未被引用且 GPU 已彻底执行完相关指令后，才执行物理释放。
    \item \textbf{Bindless 材质系统}：系统通过全局描述符集管理场景资产。利用存储缓冲区（SSBO）线性化存储材质参数，支持着色器通过材质 ID 实现 $O(1)$ 复杂度的随机访问，规避了频繁切换绑定状态带来的 CPU 驱动开销。
\end{itemize}

\subsection{混合渲染管线的通道化压缩实现}
为了优化 GPU 显存带宽并提升射线查询效率，本系统在 \texttt{HybridRenderPath} 中实现了信号生成的通道化压缩（Packing）方案：
\begin{itemize}
    \item \textbf{多信号合并探测}：系统通过统一的 \texttt{RTShadowPass} 同时执行实时阴影与环境光遮蔽（AO）的探测。利用蓝噪声（Blue Noise）抖动，阴影信号被写入目标纹理的 R 通道，而 AO 信号则被写入 G 通道。
    \item \textbf{共享加速结构遍历}：这种设计允许在单次光线追踪调用中复用 TLAS 遍历结果，极大地压低了 1 SPP 采样率下的硬件开销。系统为合并后的信号配置了自适应的 SVGF 降噪实例，在重建阶段通过分量提取分别恢复出纯净的阴影与 AO 场。
\end{itemize}

本系统将资源管理、场景层级、管线参数调节及 GPU 耗时监控高度集成于统一的控制面板（由 \texttt{EditorLayer} 实现），如图 \ref{fig:editor_ui_integrated} 所示。该界面支持在运行时动态切换渲染路径、实时调节降噪步长并预览中间 G-Buffer 附件，极大地提升了混合渲染算法的调试效率。

\section{性能定量评估与分析}

\subsection{各阶段 GPU 耗时统计}
利用渲染图内置的硬件时间戳，对 Sponza 场景在 1080P 分辨率下的各渲染阶段进行统计分析：
\begin{itemize}
    \item \textbf{G-Buffer 采集阶段}：0.68ms (主要受显存带宽限制)；
    \item \textbf{光线追踪探测 (Shadow/AO/Refl)}：3.20ms (RT Core 高效求交并行)；
    \item \textbf{SVGF 重建阶段}：1.85ms (Compute Shader 跨步滤波计算)；
    \item \textbf{后期合成与 TAA}：0.92ms；
    \item \textbf{总帧时间}：约 6.65ms (对应帧率稳定在 150 FPS 以上)。
\end{itemize}

实验结果表明，系统在高性能移动 GPU 环境下表现卓越，远超 60 FPS 的实时性基准，且 RenderGraph 的显存复用策略有效降低了显存峰值。
